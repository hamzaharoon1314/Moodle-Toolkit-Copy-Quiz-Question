# 🧠 Moodle Toolkit – Copy Quiz Question

> ⚡ A powerful userscript to take control of Moodle quizzes — remove restrictions, enable right-click, and copy questions instantly.

---

## 🚀 Features

* ✅ Enable **right-click** on restricted Moodle pages
* 📋 Copy entire **quiz questions instantly**
* ⚡ Clean floating UI button with feedback toast
* 🌍 Works on **any Moodle site** (`/mod/quiz/`)
* 🧩 Lightweight & fast (no dependencies)
* 🔒 Runs locally — **no data tracking**

2. Download the script from GitHub

3. Open your userscript manager → **Create New Script**

4. Paste the code and save

## 🧠 How It Works

* Automatically detects Moodle quiz pages (`/mod/quiz/`)
* Injects a floating **"Copy Question"** button
* Removes restrictions like:

  * Right-click blocking
  * Selection disabling
* Copies quiz content directly to your clipboard
